# NodeCloak 3.1.3

Release: https://github.com/nodecloak/nodecloak/releases/tag/v3.1.3

- 偏好设置新增“开机自动启动”，首次运行默认开启，可随时关闭；关闭后保留你的选择。
- 电脑环境和环境概览直接显示上次检测结果及时间，点击“重新检测”获取最新结果。
- 修复记录独立加载并保留最近读取的记录，点击“刷新记录”更新；修复或撤销后，相关记录同步更新。

- Adds Launch at login in Preferences, enabled on first run. Turning it off preserves your choice.
- Computer environment and Environment overview show the last results and check time immediately. Use Check again for fresh results.
- Repair history loads independently and keeps recently loaded records. Refresh history reloads records; repairs and restores update related history.

已有浏览器副本、登录数据和修复记录继续保留。

Existing browser profiles, website sessions and repair history are preserved.
