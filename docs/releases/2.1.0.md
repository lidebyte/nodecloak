## Changes

- Share an independent browser profile snapshot with a registered friend by matching username and email. Set or change expiry and revoke access.
- Recipients must accept an invitation before use. Sharing can be sent before personal cloud device approval; recipients explicitly authorize their current device inside the acceptance flow without opening cloud sync settings.
- Sharing defaults to browser configuration, with optional sign-in data. Received profiles retain usage restrictions and stop after expiration, revocation or lost authorization. Sender profiles remain independent.
- Manage sent and received invitations in the Sharing page; remove its introductory card.
- Update the Google sign-in icon and make the homepage banner follow light and dark themes.
