## User-visible changes

- MCP automation connects compatible AI clients to explicitly authorized profiles for page reading, form entry, clicks, screenshots and selected folders.
- Remote MCP connects approved devices to remote clients with scopes for profiles, website origins, folders and operations.
- MCP cloud-sync tools inspect synchronization, preview changes, sync selected profiles and resolve conflicts.
- Chrome, Edge and Firefox use the same authorized browser-operation flow.
- Profile page control and synchronization status feedback are clearer during automation.
