## User-visible changes

- Persistent, independent profile fingerprint seeds with explicit regeneration and five independently adjustable readback protections.
- Batch profile start, close, deletion and restoration; enhanced regional, hardware-hint, viewport and privacy settings.
- Partitioned website-session migration preserving site isolation and local data, plus more reliable profile navigation.

Detailed coverage and limitations: `../specs/stable-profile-fingerprints-validation.md`, `../specs/browser-environment-enhancements.md` and `../specs/partitioned-session-storage-validation.md`. Firefox fingerprint preload covers Windows/iframes; Firefox Worker readback remains outside this implementation. Installed-browser integration was exercised on Windows, not claimed as macOS browser integration.
