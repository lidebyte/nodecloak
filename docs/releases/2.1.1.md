## Changes

- Original local profiles can start when optional personal session sync encounters unsupported Firefox partitioned storage. Existing local login data, sync baselines and pending remote session revisions are preserved. Explicit session exports and recipient authorization checks remain enforced.
- Profile operation errors survive list polling and native refresh events. Users can dismiss the message or retry the operation.
