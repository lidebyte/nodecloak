## Recovery safeguards

Missing local registry entries remain distinct from explicit profile deletions. The UI provides cloud configuration recovery and unlinking with clear consequences and inline confirmation, and retrieves known cloud names rather than calling missing entries deleted. The backend checks the current cloud revision before applying configuration. Recovered profiles reuse their existing browser directory. Session comparisons are reinitialized with the authenticated checkpoint retained, so an empty recovered directory may receive the cloud session while nonempty differences require a separate decision.

The frontend regressions first failed on the absent actions and incorrect names. The isolated two-device regression first failed on the incorrect deleted-profile name and then on stale session bookkeeping, before passing with the fixes. Original user data has not been modified by these synthetic tests.
