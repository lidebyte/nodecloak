# NodeCloak 3.2.0 release plan

**Goal:** Publish the confirmed environment-reset feature to Windows x64, macOS Apple Silicon and Intel, with GitHub, in-app update and website downloads aligned.

**Architecture:** Use the existing tagged build matrix, inspect its draft assets, apply the existing platform package procedure and version-bound update checks, then publish and atomically switch the verified website root.

**Constraints:** Follow AGENTS.md for product-only public notes. Preserve existing profiles during release; the reset action only runs after explicit per-profile confirmation. Use synthetic/disposable data for tests. No account-service deployment, shutdown or hibernation. No macOS 27 user-machine result claimed.
