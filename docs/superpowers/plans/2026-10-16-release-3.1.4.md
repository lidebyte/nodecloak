# NodeCloak 3.1.4 release plan

**Goal:** Publish the validated multi-device synchronization improvements to all supported packages, GitHub, the website and the in-app updater.

**Architecture:** Backward-compatible account-service rollout first; tagged desktop build matrix; final package verification; atomic website switch.

## Constraints

- Preserve account credentials, database contents, existing profiles and login data. Never run destructive integration fixtures against production.
- Public release notes contain only user-visible product changes under AGENTS.md.
- Keep existing updater key, sign all four packages through existing platform processes, and verify application bytes, code signatures, certificate result and updater signatures separately.
- User previously authorized reuse of the existing Windows certificate. Actual certificate validation is recorded privately and reported in chat.
- No shutdown or hibernation.

## Steps

- [x] Align versions/notes and complete final preflight.
- [ ] Commit/push source and tag v3.1.4; complete all platform jobs and draft aggregation.
- [x] Back up private service configuration/database; deploy immutable account binary with rollback; verify health, route protection, unchanged schema and credentials.
- [ ] Apply Windows signing and create final updater signature; verify all assets, package versions and hashes.
- [ ] Publish GitHub release and update/test/commit website source.
- [ ] Stage/check website files, switch atomically, verify public downloads/update indices/service health.
- [ ] Record final evidence and clean temporary staging.
