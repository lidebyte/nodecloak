# NodeCloak 3.1.3 Release Implementation Plan

> **For agentic workers:** Execute the checked release steps sequentially and preserve existing user profiles.

**Goal:** Publish launch-at-login preferences and cached environment/history views for Windows x64 and macOS ARM64/Intel.

**Architecture:** Use the tagged GitHub Actions matrix to build all platforms and stage a draft. Apply the existing Windows signing procedure, verify updater signatures and hashes, then publish GitHub assets and atomically switch the website static root.

**Tech Stack:** Tauri/Rust, React/Vite, GitHub Actions, static website, pinned SSH deployment.

**Spec:** User requests for cached environment/history navigation, default-on launch at login, and signed publication of every supported platform.

## Global Constraints

- Follow AGENTS.md: public notes describe user-visible product behavior only.
- Preserve browser profiles, cloud bindings and user login data. No sleep or shutdown.
- Include Windows x64 installer/portable, macOS ARM64/Intel DMGs and all three updater payloads.
- Respect explicit startup opt-outs and isolate development startup entries.
- macOS native APIs must compile and regression tests pass on both runner architectures; do not claim an actual reboot test from Windows.

## Release steps

- [x] Align package/lock/Cargo/Tauri versions at 3.1.3 and update user-facing notes.
- [x] Review source; run frontend, script, Rust and production-build preflight.
- [x] Commit/push source and tag; await all platform checks and draft aggregation.
- [x] Apply Windows signing to portable, embedded app and installer; independently verify signature, program bytes and certificate status.
- [x] Sign the final Windows updater; verify all updater payloads, package versions and checksums.
- [x] Publish the complete GitHub release; update and test website notes and downloads, commit/push website.
- [x] Stage and verify every static file before atomic deployment; verify public downloads, manifests and service health.
- [x] Record final release/deployment evidence.
