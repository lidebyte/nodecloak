# NodeCloak 3.1.5 release plan

**Goal:** Publish the validated Firefox fingerprint, regional setup and startup fixes to GitHub, the website and the in-app updater.

**Architecture:** Use the tagged Windows/macOS matrix, verify its draft packages, apply the existing Windows signing procedure and updater signature, then publish and atomically switch the website root.

**Constraints:** Preserve existing profiles, credentials and login data. No account-service deployment is needed. Public notes describe user-visible behavior only under AGENTS.md. Preserve the updater key and use the previously authorized platform credentials. No shutdown or hibernation. VLESS/VMess are not implemented or included in the notes.
