# 使用 MCP 连接 NodeCloak

NodeCloak 可通过本机 stdio 或远程 Streamable HTTP MCP 连接，让 AI 客户端管理指定的浏览器副本，并在 Chrome、Edge、Firefox 中读取和操作网页。浏览器在获准的桌面设备上运行。

## 添加连接

1. 打开桌面端，点击左侧栏的「MCP」。
2. 启用 MCP，点击「添加客户端」，填写名称。
3. 选择这个客户端可以访问的副本、操作权限和授权期限。可限定网站来源，例如 `https://example.com`，每行一个。
4. 使用上传和下载时，选择允许访问的本地文件夹。新建客户端默认直接执行点击、填写和导航，可按客户端开启「网页操作前确认」。已有客户端保留原设置。
5. 创建授权后，点击「连接配置」，将生成的 JSON 添加到支持 stdio 的 MCP 客户端。保持 NodeCloak 桌面端运行。

配置自动填写当前安装的程序路径和授权标识，不需要手写端口，也不包含令牌。程序移动位置或更换安装目录后，重新复制连接配置。

## 接入 Codex

在 Codex 的「设置 → MCP 服务器」中添加 STDIO 连接：名称填写 `nodecloak`，启动命令填写 NodeCloak 连接配置中的 `command`，参数逐项填写 `args`，保存并重启该连接。

也可以使用 `codex mcp add nodecloak -- <程序路径> <参数>` 注册连接，再用 `codex mcp get nodecloak` 检查。Codex 使用 `~/.codex/config.toml` 保存配置。详见 [Codex MCP 官方说明](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。

设置网站白名单时，将实际跳转目标也加入授权，例如 `https://example.com` 和 `https://www.example.com`。整页截图还会检查页面内 iframe 的来源；用户可按需要为这些来源授权。

## 权限

| 权限 | 可以做什么 |
| --- | --- |
| 读取副本信息 | 查看获准访问的副本、指纹配置、服务状态和自己的任务 |
| 管理副本 | 新建、编辑、复制、启动、关闭、移入回收站、恢复副本，检测代理，重新生成指纹 |
| 读取网页 | 查看标签页与 iframe、读取页面快照、截图、等待页面内容 |
| 操作网页 | 打开和关闭标签页、导航、点击、填写、选择、滚动、处理网页弹窗 |
| 上传和下载 | 选择授权目录中的文件进行上传，查看此客户端的下载文件 |
| 同步副本 | 查看同步状态、预览选定副本的变更、执行同步并处理冲突 |

新建或复制的副本自动加入创建它的客户端授权。新副本使用独立指纹，重启后继续保持。删除副本、重新生成指纹和上传文件始终需要在桌面端确认。

在「已授权客户端」中可直接调整本机客户端的同步权限和网页确认设置。远程连接增加权限时，重新发起 OAuth 授权并在桌面端确认范围。

## 远程连接

需要先部署支持远程 MCP 的账号服务，再使用对应版本的桌面端。当前源码已提供网关实现；本地验证不代表线上服务已部署。

1. 登录桌面端，完成设备授权，打开「MCP → 远程连接」，启用 MCP。
2. 在支持 OAuth 的 AI 客户端添加界面显示的 MCP 地址，默认是 `https://nodecloak.com/mcp`。
3. AI 客户端打开授权网页后，在桌面端输入网页上的授权码，点击「查看授权请求」。
4. 核对客户端、回调地址，选择可访问的副本、网站、文件目录、权限和有效期，确认授权。
5. 保持桌面端在线。网页自动返回 AI 客户端，连接状态随设备心跳更新。

每个远程 OAuth 客户端使用独立授权，浏览器操作仍受桌面端权限检查。网页内容和截图会通过 NodeCloak 网关传给这个 AI 客户端。账号令牌、恢复密钥与原始网站登录数据不会作为 MCP 结果提供。

撤销连接、退出账号、授权到期或关闭 MCP 后会停止接收相应操作。断线后的操作不会自动重放；已经发送到浏览器的操作无法撤销。取消任务后，先查看实际页面状态再决定下一步。

## 通过 MCP 同步

先在桌面端完成云端同步初始化、保存恢复密钥，并关联需要同步的副本。给客户端开启「同步副本」权限后：

1. `sync_status` 传入 `profile_ids`，查看选定副本的同步信息。
2. `sync_preview` 获取变更预览及 `preview_id`。
3. 核对预览后，`sync_run` 使用相同的 `profile_ids` 和 `preview_id` 执行。
4. 存在冲突时，用新的预览调用 `sync_resolve`，在桌面端确认处理方向。保留双方版本需要同时拥有管理副本权限。

预览有效期十分钟，绑定客户端、账号和本地/云端版本。版本变化后需要重新预览。调用只处理授权且选定的已关联副本；网站登录状态同步沿用桌面端设置、关闭浏览器检查和设备租约保护。预览只提供状态、动作与冲突信息。

## 典型任务

可以对连接的 AI 说：

> 列出我授权的副本，启动其中的工作副本，打开指定网站，读取页面标题和表单，填写草稿，提交前让我确认。

工具调用顺序：

1. `profiles_list` 获取副本 ID，再用 `profiles_start` 启动受控浏览器。
2. `tabs_open` 打开页面，可传 `task_id` 为本次任务标记新建的标签页。
3. `page_wait` 等待内容，`page_snapshot` 获取页面文本、`snapshot_id` 和元素 `ref`。
4. `page_click` / `page_fill` / `page_select` 使用刚获取的快照和元素引用。iframe 先用 `frames_list` 获取 `frame_id`。
5. 需要图片时调用 `page_screenshot`，结果包含 MCP 图片内容块。
6. 任务完成后用 `tabs_cleanup` 关闭该客户端、该任务创建的标签页。

同一副本的下载设置由当前操作的客户端独占，直到相关标签页（含弹出页）关闭且已开始的下载完成。其他客户端可继续读取，网页写操作需要等待，或使用另一个副本。任务期间，该副本的手动下载也沿用当前下载设置；结束后用 `tabs_cleanup` 或手动关闭相关页面，恢复浏览器默认下载。操作原有页面时，该页也属于相关页面。撤销或到期会禁止新的下载；已开始的传输可以完成。

每次工具调用返回任务对象，包含 `id`、`state`、`result` 和 `error`。处于 `queued`、`running` 时，用 `jobs_get` 查询；处于 `awaiting_approval` 时，到桌面端「待确认操作」查看和批准。`jobs_cancel` 可停止后续步骤。已经完成的网页操作会保留实际结果。

确认界面显示操作参数、页面和元素目标。输入内容默认折叠，可以展开核对。网页或目标在确认期间发生变化时，需要重新读取并申请确认。审批十分钟后过期。

## 工具清单

- 服务与任务：`nodecloak_status`、`jobs_get`、`jobs_cancel`。
- 副本：`profiles_list`、`profiles_get`、`profiles_create`、`profiles_update`、`profiles_clone`、`profiles_start`、`profiles_stop`、`profiles_trash`、`profiles_restore`、`profiles_test_proxy`。
- 指纹：`fingerprint_get`、`fingerprint_regenerate`。
- 标签页与框架：`tabs_list`、`tabs_open`、`tabs_close`、`tabs_cleanup`、`frames_list`。
- 网页：`page_navigate`、`page_snapshot`、`page_screenshot`、`page_click`、`page_fill`、`page_select`、`page_scroll`、`page_wait`、`page_dialog`、`page_upload`、`downloads_list`。
- 同步：`sync_status`、`sync_preview`、`sync_run`、`sync_resolve`。

## 使用提示

已通过普通方式启动的副本，需要先关闭，再通过 MCP 启动，才能接入页面控制。副本保留原有网站数据和指纹配置。

导航、更换文档或读取下一份快照后，重新获取元素引用。新标签页即使导航失败也会返回 `tab_id` 和错误详情，客户端仍可管理或清理它。

获准读取的页面文本和截图会发送给所连接的 AI 客户端。授权凭据保存在系统凭据管理器中。桌面端保留最近 128 条脱敏任务记录，页面内容、截图和填写值不写入持久记录。

到「已授权客户端」可随时撤销连接。关闭 MCP 会停止接收操作并取消尚未执行的任务。授权按本机系统用户保存，每台设备分别配置。

远程网关中的任务参数和结果使用认证加密存储，任务十五分钟后到期；后台清理在服务健康运行时于随后一分钟内移除过期载荷。数据库备份保留期由部署方单独配置。桌面端重复投递记录仅保存任务标识和状态，用于防止重复执行。
